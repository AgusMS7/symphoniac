# Créditos de imágenes de seed

Las 30 imágenes de `backend/src/main/resources/static/images/` son fotografías
de stock de [Pexels](https://www.pexels.com/), usadas como referencia visual de
los instrumentos ficticios del catálogo. No son productos reales ni implican
una relación comercial con las marcas mencionadas en el seed.

- Licencia: [Pexels License](https://www.pexels.com/license/).
- Formato final: JPEG progresivo, 960 x 1200 px (4:5), calidad 80, recortadas
  para el catálogo. La guitarra acústica se guardó a 800 x 1000 px para
  mantener el peso bajo 150 KB.
- Ajustes: las fotos se recortaron para el encuadre 4:5. Cuando una pala,
  tapa o tapa de armónica mostraba una marca legible, se recortó o se
  difuminó esa zona para cumplir la consigna de no mostrar marcas visibles.
